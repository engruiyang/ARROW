# ARROW 弓箭环数识别技术方案

## 1. 项目定位

ARROW 的第一阶段目标是面向民用射箭馆的自动辅助判环系统。系统不按正式比赛级精度设计，允许约 5% 的自动误判，并保留人工复核入口。第一版 Demo 重点验证完整工程链路：输入前后图片、检测新增箭支、估计入靶点、计算环数、输出可视化结果。

当前阶段明确收敛范围：只针对 90 靶纸；只处理图片序列或前后图片差分；不接入实时视频流；不引入 RTSP、FFmpeg、采集卡、网络解码器等视频链路代码；不优先训练深度学习模型。

## 2. 现场考察结论

### 2.1 已测关键数据

- 摄像头到靶面的纵向距离：3200 mm
- 摄像头与靶心高差：约 1000 mm
- 摄像头中心离地高度：2500 mm
- 靶心离地高度：1430 mm
- 摄像头俯仰角：约 17.4°
- 摄像头并非只对应单个靶心，每个摄像头大致覆盖两个草靶
- 草靶中心距离：约 750–800 mm
- 现场视频参数：1080P，25 FPS，延迟小于 50 ms

### 2.2 靶纸规格

本阶段只启用 90 靶纸参数：

- 90 靶纸外径：490 mm
- 外圆半径：245 mm
- 靶心内径：90 mm
- 靶心半径：45 mm
- 环线径向间距：50 mm
- 环线宽度：1 mm

80 / 60 / 40 靶纸暂不进入 Demo 范围。特别是 40 靶在现有摄像头视角下占比过小，环线接近人眼不可见，早期处理价值较低。

### 2.3 草垛表面问题

现场草垛垛芯存在数厘米级突起，不同草垛之间差异明显。因此算法不能把草垛表面当作理想平面，也不建立草垛三维模型。第一版只使用靶纸自身的印刷几何作为坐标参考，草垛纹理、凸起、阴影都视为背景干扰。

## 3. 第一版技术选择

推荐方案为：

```text
图片序列输入
→ 手动或半自动靶面标定
→ 90 靶几何模型
→ 前后图片差分
→ 新增箭支区域提取
→ 箭杆线段拟合
→ 入靶点估计
→ 半径判环
→ 可视化输出与人工修正
```

采用 Python + OpenCV 实现。第一版不使用深度学习，理由是场景固定、靶纸结构固定、颜色边界明显、样本数量有限，传统视觉更容易快速落地，也更便于调试和解释。

视频流后续可以作为独立输入适配器开发，但不进入当前代码主线。实际部署即使每秒输入一张图片，也足够覆盖民用射箭馆的使用节奏。若出现极端连射情况，可以通过“本轮新增目标数量大于 1”提示人工复核。

## 4. 输入与输出定义

### 4.1 输入

第一版支持两种输入形式：

1. 图片序列文件夹：按文件名排序，相邻图片做差分。
2. 前后图片对：指定 before / after 两张图片，输出新增箭判断结果。

输入图片应来自同一固定机位。推荐测试数据为实地包中的“草垛上——带箭靶纸 / 多只箭-摄像头”完整着箭周期。

### 4.2 输出

每次处理输出：

- 新增箭支编号
- 入靶点像素坐标
- 入靶点归一化坐标
- 入靶半径估计值，单位 mm
- 估计环数
- 置信度：high / medium / low
- 带标注结果图
- JSON 或 CSV 结果记录

低置信度结果不强行作为最终分数，应进入人工复核。

## 5. 标定策略

第一版使用半人工标定，避免把开发时间消耗在复杂自动识别上。

标定信息包括：

- 靶纸 ROI
- 靶心位置
- 外圆椭圆参数，含中心、长轴、短轴、旋转角
- 90 靶纸物理尺寸参数

由于摄像头存在俯仰角和一定透视畸变，图像中的圆靶可近似为椭圆。判环时将入靶点映射到归一化椭圆坐标，再换算为真实半径。

归一化半径计算思路：

```text
将点坐标平移到靶心
按外圆椭圆方向旋转
分别除以外圆半长轴和半短轴
得到归一化坐标 x_norm, y_norm
r_norm = sqrt(x_norm^2 + y_norm^2)
r_mm = r_norm * 245
```

这样可以绕开对草垛平面的理想化假设，也能适应摄像头轻微偏斜。

## 6. 差分检测策略

### 6.1 基本流程

对相邻两张图片进行处理：

```text
读取上一张稳定图 prev
读取当前图 curr
裁剪靶纸 ROI
做亮度归一化
计算 absdiff(prev, curr)
阈值分割新增区域
形态学去噪
保留细长结构或与箭杆方向一致的区域
输出新增箭候选区域
```

在现场使用节奏下，一秒一张图基本可以认为每次最多新增一支箭。若检测到多个新增细长目标，系统不直接判定全部结果，标记为 low confidence 并交给人工确认。

### 6.2 抗干扰处理

需要重点抑制以下干扰：

- 光照轻微变化
- 电视画面或相机曝光变化造成的全局亮度差
- 草垛纹理变化
- 箭杆阴影
- 已存在箭支的细小晃动

第一版可采用灰度差分 + HSV 差分组合，并用连通域面积、长宽比、线性度过滤干扰。

## 7. 箭杆与入靶点估计

### 7.1 箭杆检测

对新增区域进行线段拟合，候选方法包括：

- HoughLinesP
- LSD 线段检测
- 连通域骨架化后做 RANSAC 直线拟合

第一版优先实现 HoughLinesP 或 RANSAC，选择工程上最稳定的一种即可。

### 7.2 入靶点估计

箭支在图像中通常表现为一条从入靶点向外延伸的细长结构。第一版可按以下规则估计入靶点：

1. 得到新增箭杆主线段的两个端点。
2. 将两个端点分别映射到靶纸椭圆坐标系。
3. 优先选择归一化半径更小、且位于靶纸有效区域内的端点作为入靶点候选。
4. 若线段与靶纸内已有遮挡重叠，使用箭杆方向向靶心侧回推，寻找新增区域边界点。
5. 若候选点不稳定，输出 low confidence 并允许用户点击修正。

该规则适合当前样本中箭杆明显向画面下方或外侧延伸的情况。后续若出现箭杆方向变化明显的靶位，可以增加按历史样本学习的方向先验。

## 8. 判环模型

第一版以 90 靶为唯一模型。根据入靶半径 r_mm 进行区间判断。

推荐配置形式：

```yaml
target_type: 90
outer_diameter_mm: 490
outer_radius_mm: 245
center_diameter_mm: 90
center_radius_mm: 45
ring_width_mm: 50
line_width_mm: 1
max_score: 10
ring_scores: [10, 9, 8, 7, 6]
```

边界半径：

```text
45 mm, 95 mm, 145 mm, 195 mm, 245 mm
```

基础判分：

```text
r_mm <= 45       → 10
45 < r_mm <= 95  → 9
95 < r_mm <=145  → 8
145< r_mm <=195  → 7
195< r_mm <=245  → 6
r_mm > 245       → miss / outside
```

民用射箭馆 Demo 阶段不做严格比赛级压线判罚。若后续需要压线按高环计算，可以加入箭杆半径修正：

```text
r_effective = r_mm - arrow_radius_mm
```

然后用 r_effective 判环。

## 9. 置信度与人工复核

系统不追求完全无人干预。以下情况应输出 low confidence：

- 检测到不止一个新增箭状目标
- 新增区域过短或过碎
- 箭杆线段拟合失败
- 入靶点靠近环线边界
- 入靶点落在靶纸外圆附近
- 多支箭严重遮挡靶心区域
- 当前图和上一图存在明显位移或曝光突变

人工复核方式可以很简单：在可视化图上点击正确入靶点，系统重新计算环数，并把修正结果写入记录文件。

## 10. 第一版验收目标

Demo 验收标准：

- 能读取实地图片序列并按顺序处理
- 能完成 90 靶半人工标定
- 能在多数相邻图片中检测新增箭支
- 能输出入靶点、环数和可视化结果
- 对明显非争议箭给出合理环数
- 低置信度样本可进入人工修正
- 自动判分误判率目标控制在约 5% 量级；若样本量较少，以人工复核后的可用性为主

## 11. 暂不进入第一版的内容

- 实时视频流接入
- RTSP / RTMP / SRT / HLS 读取
- HDMI 采集卡输入
- 40 靶、60 靶、80 靶自动识别
- 草垛三维表面重建
- 比赛级压线判罚
- 深度学习模型训练
- 多靶位自动切换
- 多射手身份识别

## 13. 第一批开发任务

1. 建立 Python 项目骨架和命令行入口。
2. 支持读取图片序列，并按文件名排序生成相邻图片对。
3. 实现 90 靶参数配置与半径判环函数。
4. 实现手动标定文件读取与保存。
5. 实现前后图片差分，输出新增区域 mask。
6. 实现箭杆线段拟合与入靶点候选估计。
7. 实现结果图可视化，画出靶心、环线、箭杆、入靶点、分数。
8. 实现 JSON / CSV 结果导出。
9. 增加低置信度标记与人工修正入口。

## 14. 当前最终技术结论

ARROW 第一版采用“90 靶 + 图片差分 + 传统视觉 + 几何判环 + 人工复核”的方案。这条路线符合民用射箭馆需求，开发成本低，结果可解释，能容忍现场草垛不平整和视频链路暂不可用的问题。当前阶段不需要接入视频流，也不需要为视频流保留复杂代码结构。等图片差分链路跑通后，再根据实际部署需求决定是否扩展输入来源。
